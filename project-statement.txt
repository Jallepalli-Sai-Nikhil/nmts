5. ROLES
-------------------------------------------------------------
Role enum (used in JWT claim "role" and X-User-Role header):
  MINING_AGENCY, CUSTOMER, ADMIN, REPORTER, GOV_OFFICER

MINING_AGENCY can:
  - Register and login
  - Create/update their agency profile
  - Create metal listings (price per ton, quantity, metal name)
    ONLY if they hold an ACTIVE license
  - Update and soft-delete their own listings
  - View incoming purchase requests
  - Approve or reject purchase requests
  - View their own license status

CUSTOMER can:
  - Register and login
  - Update their own profile
  - Search metals by name → see agencies with active license
  - View listing details (price per ton, agency info)
  - Send a purchase request (quantity + optional message)
  - View their own purchase requests and history

ADMIN can:
  - View all agencies, users, listings, purchase requests,
    reports, licenses, seizure orders
  - View platform statistics
  - Deactivate / reactivate any user account
  - Access the analytics dashboard (ADMIN ONLY)

REPORTER can:
  - Register and login
  - File a compliance report against an agency
  - View and update their own PENDING reports

GOV_OFFICER can:
  - Grant / revoke licenses with types:
    DAY_60 (60 days), DAY_70 (70 days), DAY_90 (90 days),
    CUSTOM (caller provides durationDays)
  - Review compliance reports, update their status
  - Issue seizure orders against agencies
  - View all licenses and seizure orders

JwtAuthenticationFilter (implements GlobalFilter):
  Skip for: POST /auth/register, POST /auth/login
  For all other requests:
    1. Extract Authorization: Bearer <token>
    2. Validate JWT signature with nmts.jwt.secret from config
    3. Invalid/missing → return 401 JSON:
       { "status": 401, "error": "Unauthorized",
         "message": "Invalid or missing token" }
    4. Valid → mutate request, add headers:
         X-User-Id:    <sub claim (UUID string)>
         X-User-Role:  <role claim>
         X-User-Email: <email claim>

7. FEIGN CLIENT PATTERN
-------------------------------------------------------------
Every inter-service HTTP call MUST use a Feign client.
No RestClient, no WebClient, no RestTemplate.

Each service that calls another service defines a Feign interface
in its own codebase under package:
  com.nmts.{servicename}.client

Example (mining-agency-service calling license-service):

  @FeignClient(name = "license-service", path = "/licenses")
  public interface LicenseServiceClient {
    @GetMapping("/agency/{agencyId}/status")
    LicenseStatusDTO getAgencyLicenseStatus(
        @PathVariable UUID agencyId);
  }

Add @EnableFeignClients to every business service Application.java.
Feign resolves lb://license-service via Eureka automatically.

Feign client interfaces needed (define inside the CALLING service):

  In mining-agency-service:
    LicenseServiceClient → GET /licenses/agency/{agencyId}/status

  In search-catalog-service:
    MiningAgencyServiceClient →
      GET /agency/listings/search?metalName={name}
    LicenseServiceClient →
      GET /licenses/agency/{agencyId}/status

  In government-service:
    ReportServiceClient →
      GET /reports/internal/all (paginated)
      PATCH /reports/internal/{id}/status
    MiningAgencyServiceClient →
      PATCH /agency/{id}/status

  In analytics-service:
    MiningAgencyServiceClient →
      GET /agency/all?page=0&size=1000
      GET /agency/purchase-requests/all?page=0&size=1000
    LicenseServiceClient →
      GET /licenses/all?page=0&size=1000
    ReportServiceClient →
      GET /reports/internal/all?page=0&size=1000
    GovernmentServiceClient →
      GET /government/seizures/all?page=0&size=1000

── AnalyticsController (base: /analytics) ───────────────────
ALL endpoints: ADMIN only

  GET /analytics/summary
    Returns: PlatformSummaryDTO
    Logic (combine MongoDB counts + Feign snapshot):
      - totalAgencies: count AgencyEventDocument
      - activeAgencies: call MiningAgencyServiceClient,
          count where operationStatus=ACTIVE
      - seizedAgencies: count AgencyEventDocument
          where eventType=SEIZED
      - totalListings: count ListingEventDocument
      - activeListings: call MiningAgencyServiceClient,
          count active listings
      - Purchase counts: count PurchaseEventDocument
          by eventType
      - License counts: count LicenseEventDocument
          by eventType
      - Report counts: count ReportEventDocument
          and call ReportServiceClient for status breakdown
      - totalSeizures: count SeizureEventDocument

  GET /analytics/reports/by-severity
    Returns: ReportsBySeverityDTO
    Logic: count ReportEventDocument grouped by severity
    MongoDB aggregation:
      db.report_events.aggregate([
        { $group: { _id: "$severity", count: { $sum: 1 } } }
      ])

  GET /analytics/purchases/trend
    Returns: List<PurchaseTrendDTO>
    Param: months (default 6)
    Logic: group PurchaseEventDocument by
      year-month of timestamp and eventType
    Returns last N months of purchase activity

  GET /analytics/metals/top
    Returns: List<TopMetalDTO>
    Param: limit (default 10)
    Logic: group PurchaseEventDocument by metalName,
      aggregate totalRequests, totalQtyTons, totalValue
      Sort by totalRequests DESC, take top N

  GET /analytics/agencies/performance
    Returns: List<AgencyPerformanceDTO>
    Logic: group PurchaseEventDocument by agencyId,
      count approvedSales, sum totalValue
      Cross-reference with ListingEventDocument
        for totalListings count
      Sort by approvedSales DESC

  GET /analytics/licenses/activity
    Returns: List<LicenseActivityDTO>
    Param: months (default 6)
    Logic: group LicenseEventDocument by
      year-month of timestamp and eventType
    Returns last N months of license activity

  GET /analytics/seizures/all
    Returns: List<SeizureEventDocument>
    Logic: return all seizure events from MongoDB,
      ordered by issuedAt DESC

    { success: boolean, message: String, data: T }

    com.nmts.{servicename}.client

    com.nmts.{servicename}.kafka.event

    com.nmts.{servicename}.dto
- Place entities in package:
    com.nmts.{servicename}.entity
